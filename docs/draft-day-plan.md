# Picks 48/49: read your lane
Score your 3 players (12, 13, 25) in each of the 9 categories:
- **2+ strong** in a category → double down
- **2+ weak** → punt it
- **Mixed** → target it with pick 48

Gut check:
- FT% already hurt by a big (Giannis/Şengün type)? → **Build B**. Target REB/BLK.
